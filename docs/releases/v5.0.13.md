# Fame Codex v5.0.13

This release reduces CPU usage while multiple ChatGPT Web sessions stream responses, without changing response parsing, tool handling, or conversation lifecycle behavior.

- Keeps the existing 250 ms polling cadence while acquiring a response and around tool, completion, and recovery boundaries.
- Uses a conservative 400 ms cadence during ordinary streaming and 500 ms for responses longer than 16,000 characters.
- Preserves the existing DOM projection, Markdown reconciliation, multipart flow, retained tabs, and runtime lifecycle.

Validation includes version synchronization, TypeScript type checking, runtime bundling, browser worker contract coverage, and focused streaming and Markdown reconciliation tests.
