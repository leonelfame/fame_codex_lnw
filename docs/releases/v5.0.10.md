# Fame Codex v5.0.10

This stable release carries forward the application code from v5.0.10-alpha.2, with the version updated to v5.0.10.

## Changes

- Complete Thai launcher translations and English/Thai selection in onboarding, Settings, tray menus and confirmation dialogs. Previously saved Chinese/Japanese language preferences reset to the English fallback without discarding other preferences.
- Repair uniquely identified, unchanged interrupt hooks during explicit Install/Reinstall after formatting, comments or hook positions change. Changed behavior, duplicate hooks and conflicting trust settings still stop automatic repair.
- Back up config and installation journals before repair, preserving unrelated settings.
- Execute Windows interrupt hooks with PowerShell-compatible literal quoting and its call operator.

## Validation and known limitations

The alpha.2 candidate passed its multi-platform Release workflow. Local validation included 65 focused tests, runtime and launcher typechecking, renderer build, and a headless renderer flow covering Thai onboarding, Setup, Settings and switching back to English. Native Codex catalog and interrupt smoke tests passed during alpha.1 validation.

The full repository suite is not green: alpha.1 recorded 13 failures that also reproduced on the previous baseline, including DEV/browser-partition fixtures and a Bigger Context timeout. The launcher suite was not fully completed; an isolated retry of its failing initial-health-cleanup test passed. Authenticated ChatGPT, Full-mode tools, Voice, compaction and interactive upgrades have not been revalidated across every supported platform. The stable designation does not add new account-bound validation evidence.

## Updating

Install v5.0.10, select Thai or English in Settings, and use Install/Reinstall if the Codex integration needs repair. Keep the launcher open, fully quit Codex including background processes, then reopen it to refresh the model picker.

Pre-repair config and journals are retained under the bridge home's `codex/repair-backups/`. If reverting a repair, restore the config and both journals together. Refused repairs require comparing the changed hook with its journal rather than deleting unrelated hooks or trust entries.
