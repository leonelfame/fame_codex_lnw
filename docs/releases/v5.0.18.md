# Fame Codex v5.0.18

This release removes animated tutorial media from the MCP setup flow.

- Removes autoplaying and looping MCP guide videos from every setup step.
- Removes the related fullscreen video overlay and unused presentation styles.
- Keeps MCP instructions, navigation, credential setup, runtime verification, and completion behavior unchanged.
- Reduces renderer assets by approximately 2.1 MB and avoids continuous video decoding during setup.

Validation includes launcher TypeScript checking, renderer contract tests, production build verification, and responsive cockpit smoke coverage.
