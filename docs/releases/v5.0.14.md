# Fame Codex v5.0.14

This release adds a production launcher Sleep mode for temporarily returning Codex CLI to its native route without uninstalling Fame Codex.

- Adds a Sleep mode switch under Settings > General after the production integration is installed.
- Removes only the managed Fame Codex route and Interrupt hook while preserving unrelated `config.toml` settings.
- Starts and verifies the managed runtime before reconnecting the route on wake.
- Preserves an intentional Sleep state across launcher restarts and managed runtime upgrades.
- Keeps the isolated DEV profile unchanged because it does not own the native Codex route.

Validation includes version synchronization, launcher type checking, a production renderer build, focused renderer and localization tests, and Electron main/preload syntax checks.
