# Fame Codex v5.0.17

This release introduces a redesigned Fame Codex desktop control center with a more direct workspace layout and lower UI overhead.

- Replaces the permanent sidebar with a focused header, workspace, connections, activity, and settings layout.
- Makes the Fame Codex F emblem the primary centered brand mark while keeping native window controls unobstructed.
- Keeps the embedded ChatGPT browser mounted across navigation so active sessions and browser state remain stable.
- Batches Activity updates and limits retained records to reduce unnecessary rendering work.
- Improves keyboard navigation, responsive layouts, and English and Thai interface consistency.
- Preserves existing setup, MCP, browser, update, and runtime behavior.

Validation includes TypeScript checking, launcher regression tests, production renderer build, and cockpit smoke coverage across desktop, compact, macOS chrome, and Thai layouts.
