# Fame Codex v5.0.10-alpha.2

This prerelease completes the launcher's English/Thai language selection and includes the interrupt-hook fixes from v5.0.10-alpha.1.

## Changes

- Translate the complete launcher copy dictionary into Thai, including setup, MCP instructions, diagnostics, activity, settings, browser controls and DEV screens. Product names, protocol terms and connector identities retain their literal names.
- Offer English and Thai in onboarding and Settings, with matching native tray and confirmation-dialog text. Remove unused Chinese/Japanese dictionaries and options.
- Preserve saved Thai preferences. Previously saved Chinese/Japanese preferences reset to an unselected language and use the English fallback; other preferences remain intact.
- Preserve connector names and local endpoints exactly when inserting them into translated diagnostics. Unknown backend errors remain unchanged for troubleshooting.
- Update locale tests and ignore local `.tmp/` debugging files.

## Validation

- Runtime TypeScript checking and launcher TypeScript/production renderer build passed.
- 9 launcher localization/state tests and 56 locale, hook and integration tests passed.
- Headless Chrome exercised the built renderer with a simulated launcher API: select Thai during onboarding, open the Thai Setup and Settings screens, switch to English, and verify the document language updates. No renderer errors occurred.
- Source diff checks and native JavaScript syntax checks passed.

This remains a prerelease. The broader-suite and authenticated multi-platform validation limitations documented in v5.0.10-alpha.1 still apply; this update does not claim a fully green repository suite or new account-bound end-to-end coverage. The renderer smoke uses a simulated launcher API and does not sign in to ChatGPT.

Download the installer for this exact prerelease to update from v5.0.9 or alpha.1. Select Thai in onboarding or Settings. If legacy hook/config drift is reported, use Install/Reinstall; fully quit and reopen Codex afterward to refresh its model picker. See the alpha.1 notes for repair backups and recovery details.
