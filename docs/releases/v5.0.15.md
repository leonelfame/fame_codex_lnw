# Fame Codex v5.0.15

This release prevents launcher setup from blocking MCP configuration while Codex model catalog verification is still pending.

- Marks Install models complete as soon as the core integration setup succeeds.
- Allows users to open MCP setup after the core integration is installed, without waiting for a model catalog request.
- Keeps MCP connection blocked while setup is busy, required credentials are incomplete, or Automatic mode has not installed the core integration yet.
- Keeps model catalog verification visible as a non-blocking restart notice.
- Updates English and Thai launcher guidance for the pending-verification state.

Validation includes version synchronization and the focused launcher renderer contract tests.
