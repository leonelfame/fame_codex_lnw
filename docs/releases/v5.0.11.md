# Fame Codex v5.0.11

This patch makes model installation compatible with Codex versions that do not request the model catalog through `openai_base_url` during startup.

- Setup now builds an augmented catalog from the installed Codex bundled catalog and writes a managed `model_catalog_json` assignment.
- The catalog, Codex config, primary journal, and recovery journal are committed as one compensated transaction.
- Journal v11 preserves current user-owned provider and catalog values when upgrading from v10 and restores them on uninstall.
- Reinstall, reconnect, inspection, and uninstall fail closed when the managed catalog is missing or changed.
- Legacy launcher-home and v3-v10 journal migrations remain reversible.

Validation includes the focused integration, interrupt-hook, model-catalog, launcher state/runtime suites, a launcher production build, and a live Codex 0.154.0 `app-server` `model/list` check showing all five ChatGPT Web models.
