# Fame Codex v5.0.16

This release restores Codex Extension compatibility after Codex 0.154 made `supports_parallel_tool_calls` mandatory in external model catalogs.

- Preserves explicit official capability values and supplies the effective Codex default only when bundled rows omit the required field.
- Enriches bundled native rows from Codex's effective model cache by slug while retaining bundled and unknown future fields.
- Clones the enriched official template for Fame Codex routes instead of maintaining a separate Codex schema.
- Validates each generated production catalog with the installed Codex binary before changing `config.toml`.
- Regenerates the managed catalog from the current Codex source whenever Sleep mode reconnects the bridge.
- Keeps catalog writes, route changes, and journal updates inside the existing compensated transaction.

Validation includes model catalog and Codex integration regression suites, TypeScript checking, version synchronization, and a live catalog smoke test against Codex CLI 0.154.0.
