# Fame Codex v5.0.12

This release refreshes the launcher interface with the Astra visual direction while preserving the existing workflows and runtime behavior.

- Adds the Galaxy F identity with a nebula-inspired static logo treatment.
- Introduces a deep navy, lavender, and ice-blue launcher palette with clearer hierarchy and spacing.
- Refines setup cards, controls, navigation states, and compact layouts without changing their actions or state logic.
- Replaces large backdrop blur effects with lightweight static surfaces and decoration.

Validation includes version synchronization, launcher type checking, a production renderer build, focused renderer and localization tests, and desktop and compact layout checks.
